# Arcadia Tactics - Mobile Design Context

## Crucial Project Rule: Strictly Mobile-First & Mobile-Only

This project is a dedicated mobile-only tactical RPG. It is NOT designed for desktop play. All UI/UX decisions, spatial layouts, typography scales, and interactive controls must prioritize portrait mobile screens and thumb-friendly physical ergonomics.

### Core Directives:
1. **Vertical Screen Economy**: Minimize persistent vertical overlays. Avoid blocking the tactical grid. Any control panel must be ultra-compact or retractable.
2. **Radial/Circular Menus**: Use retractable, floating, thumb-anchored circular dials inspired by Baldur's Gate 3 console layout for battle actions.
3. **No Solid Quadrants**: Never use heavy, solid full-screen corner background quadrants. Controls should float elegantly with individual translucent glass backgrounds to preserve 100% grid visibility.
4. **Touch Targets**: All interactive elements must have a touch target of at least 44px on mobile devices.
